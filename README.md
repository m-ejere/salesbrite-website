# Salesbrite

Salesbrite is a landing page concept for an AI-powered operational system built for UK trade businesses.

The system is designed to help tradespeople capture more jobs by:

- Answering incoming calls automatically
- Capturing customer and job details
- Booking appointments
- Sending confirmation messages
- Reducing missed calls and administrative workload

## Live Website

Visit the live website:

**[salesbrite.co](https://salesbrite.co)**

## Features

### AI Call Handling
The concept is built around an AI system that answers calls automatically, including outside normal working hours.

### Job Detail Capture
The system collects important information such as:

- Customer name
- Issue or job type
- Address
- Urgency
- Access details

### Automated Booking
Appointments can be booked directly into the business's available schedule.

### Customer Confirmations
Customers receive confirmation of their appointment details after booking.

### Interactive Demonstrations

The website includes several interactive elements:

- Animated job docket showing the AI call-handling process
- Scroll-reveal animations
- Before-and-after comparison slider
- Interactive demo/contact form
- Responsive mobile and desktop layouts
